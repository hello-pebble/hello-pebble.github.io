# 행정안전부 정부 공문서 AI 학습데이터 조회 서비스

<span class="badge outline">회사 프로젝트</span>

> 폐쇄망이라는 물리적 제약을 규제 위반 없이 아키텍처로 풀어낸 프로젝트. Java `ProcessBuilder` 기반의 **브릿지 아키텍처**로 좌초 위기의 시범 사업을 완수했습니다.

---

## Project Overview

- **구분**: 회사 프로젝트
- **기간**: 2023.08 ~ 2024.02 (6개월)
- **기술 스택**: Java, Spring MVC, Python, Wildfly, MariaDB, JSP, Chart.js
- **핵심 역할**: 파일 파싱 우회 통로 설계, ProcessBuilder 기반 연동 파이프라인 개발

---

## Intent (설계 의도)

"외부망 연결 불가"라는 규제는 협상의 대상이 아니었기 때문에, 제약을 우회하는 것이 아니라 **제약을 전제 조건으로 받아들이고 그 안에서 성립하는 설계**를 찾는 것이 과제였습니다.

Java 생태계만으로는 한글(HWP) 문서 파싱에 한계가 명확했고, 필요한 것은 Python의 로컬 파싱 생태계였습니다. 두 언어를 네트워크 없이 **하나의 서버 안에서 프로세스 레벨로 연결**한다면, 규제를 완전히 준수하면서도 기술적 한계를 넘을 수 있다고 판단했습니다.

---

## Problem (문제 정의 및 원인 분석)

- **문제**: 정부 공문서 파일(HWP 등)로부터 AI 학습용 원천 텍스트를 자동 정제·검증하는 시스템 구축이 차단되어 **시범 사업 자체가 좌초될 위기**였습니다.
- **원인**: 관공서의 물리적 폐쇄망 보안 규제로 외부 파싱 라이브러리(SaaS, 외부 의존 패키지 등)를 다운로드해 서버에 올릴 수 없었습니다. 또한 내부 WAS에서 기동 중이던 Java 파싱 라이브러리만으로는 복잡하게 구조화된 한글 파일의 텍스트·메타데이터를 정밀 파싱하는 데 기술적 한계가 명확했습니다.

---

## Solution (해결 과정)

![폐쇄망 브릿지 아키텍처](/assets/images/portfolio/gov-bridge.svg)

1. **Java-Python 브릿지 설계**
   - 네트워크 연결 없이 복잡한 이진 문서를 해독하기 위해, 풍부한 로컬 파싱 패키지를 가진 **Python 스크립트를 Java 서버 로컬 환경에 배치**하는 구조를 기획했습니다.
2. **ProcessBuilder를 활용한 서브프로세스 제어**
   - Java의 `ProcessBuilder` API로 내부 Python 가상 환경(Virtualenv)을 서브 프로세스로 직접 실행·통제하는 **격리형 실행 통로**를 구축했습니다.
3. **격리형 데이터 파이프라인 구축**
   - Java 서버가 컨트롤 타워가 되어 입력 파일을 Python 서브프로세스의 표준 입력(STDIN)으로 전달하고, 추출된 텍스트 스트림을 표준 출력(STDOUT)으로 즉시 받아 MariaDB에 영속화하는 **실시간 변환 파이프라인**을 완성했습니다.

---

## Results (최종 성과)

- **비즈니스 완수**: 폐쇄망 규제 요건을 모두 충족하는 외부 통신 없는 대체 설계를 제시하여 **정부 부처 시범 사업을 성공적으로 완수**했습니다.
- **생산성 극대화**: 문서를 수동으로 복사·붙여넣기 하던 정제 과정을 **자동화 파이프라인으로 전환하여 데이터 처리·등록 공수를 대폭 절감**했습니다.
