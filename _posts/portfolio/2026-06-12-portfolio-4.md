# 행정안전부 정부 공문서 AI 학습데이터 조회 서비스

> 폐쇄망 제약 환경을 극복하는 Java ProcessBuilder 기반 브릿지 아키텍처 설계

---

## 📌 Project Overview
- **기간**: 2023.08 ~ 2024.02 (6개월)
- **기술 스택**: Java, Spring MVC, Python, Wildfly, MariaDB, JSP, Chart.js
- **핵심 역할**: 파일 파싱 우회 통로 설계, ProcessBuilder 기반 연동 파이프라인 개발

---

## 🔍 Problem Discovery & Cause (문제 정의 및 원인 분석)
- **문제**: 정부 공문서 파일(HWP 등)로부터 AI 학습용 원천 텍스트 데이터를 자동으로 정제하고 정합성을 검증하는 자동화 시스템 구축이 차단되어 시범 사업 자체가 좌초될 위기였습니다.
- **원인**: 관공서의 강력한 물리적 폐쇄망 보안 규제로 인해 외부 파싱 라이브러리(SaaS, 외부 의존 패키지 등)를 인터넷망으로부터 다운로드하여 서버에 올릴 수 없었습니다. 또한 내부 WAS로 기동 중이던 Java 기반 파싱 라이브러리만으로는 복잡하게 구조화된 한글 파일의 텍스트와 메타데이터를 정밀히 파싱하는 데 기술적 한계가 명확했습니다.

---

## 💡 Solution (해결 과정)
1. **Java-Python 우회 브릿지 설계**
   - 네트워크 연결 없이 내부에서 복잡한 이진 문서를 해독하기 위해, 풍부한 로컬 파싱 패키지를 가지고 있는 Python 스크립트를 Java 서버 로컬 환경에 우회 배치하는 아이디어를 기획했습니다.
2. **ProcessBuilder를 활용한 서브프로세스 제어**
   - Java 자체 라이브러리 호출 대신, Java의 `ProcessBuilder` API를 사용하여 내부 파이썬 가상 환경(Virtualenv)을 서브 프로세스로 직접 실행하고 통제하는 격리형 통로를 뚫었습니다.
3. **격리형 데이터 파이프라인 구축**
   - Java 서버가 메인 컨트롤 타워가 되어 입력 파일을 Python 서브프로세스의 표준 입력(STDIN)으로 밀어 넣고, Python 파싱 모듈이 추출한 텍스트 데이터 스트림을 표준 출력(STDOUT)으로 즉시 받아 MariaDB에 영속화하는 실시간 변환 파이프라인을 성립했습니다.

---

## 📈 Results (최종 성과)
- **비즈니스 완수**: 강력한 폐쇄망 규제 요건을 모두 충족하면서도 외부 통신 없는 대체 설계 대안을 제시하여 **정부 부처 시범 사업을 성공적으로 완수**했습니다.
- **작업 생산성 극대화**: 수작업으로 문서를 수동으로 복사·붙여넣기 하던 정제 과정 대비, 전체 데이터 처리 및 등록 시간을 **70% 이상 단축**시켰습니다.
