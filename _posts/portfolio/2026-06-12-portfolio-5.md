# 사내 교육 플랫폼(LMS) 개발

> RBAC 기반의 세밀한 권한 검증 및 Oracle BLOB를 활용한 파일 일관성 확보

---

## 📌 Project Overview
- **기간**: 2020.12 ~ 2021.03 (4개월)
- **기술 스택**: Java, Spring Boot, JPA, Oracle
- **핵심 역할**: SSO 권한 인가 로직 설계, Oracle BLOB 파일 저장소 통합 구현

---

## 🔍 Problem Discovery & Cause (문제 정의 및 원인 분석)
- **문제**: 기업용 통합 플랫폼 특성상 민감한 사내 정보 노출 및 비인가 유저의 기능 권한 접근 위협이 있었고, 데이터베이스 백업 시 파일 누락으로 인한 데이터 정합성 불일치 리스크가 존재했습니다.
- **원인**: 여러 부서와 직군이 혼재된 다수 유저를 제어할 세분화된 권한 체계(SSO 연동 권한 인가)가 부재했으며, 첨부파일을 웹 서버의 로컬 디스크 파일 시스템에 직접 보관하는 전통적인 방식은 DB 백업과 파일 스토리지 백업 간의 시점 불일치를 일으켜 데이터 유실 시 복구가 매우 까다로웠습니다.

---

## 💡 Solution (해결 과정)
1. **SSO 연동 및 RBAC(Role-Based Access Control) 설계**
   - 사내 싱글사인온(SSO) 시스템과 연동한 사용자 세션 정보를 수집했습니다.
   - 역할 기반 권한 모델(RBAC)을 구조화하여, Spring Security 계층 및 API 엔드포인트 도메인 레벨에서 비인가 사용자의 요청을 원천 차단하도록 공통 권한 검증 인터셉터를 구축했습니다.
2. **Oracle BLOB 기반 파일 저장 방식 채택**
   - 파일 유실 가능성을 차단하고 백업의 단순화를 이루기 위해, 디렉토리 경로 저장 방식 대신 DB 테이블 내에 이진 대용량 데이터를 직접 담는 Oracle BLOB(Binary Large Object) 방식을 설계했습니다.
   - 이를 통해 파일 생성/수정/삭제 행위가 비즈니스 데이터 처리와 단일 DB 트랜잭션(`@Transactional`)으로 묶여 영속되도록 보장했습니다.

---

## 📈 Results (최종 성과)
- **보안 무결성 보장**: 정밀한 역할 권한 제어를 통해 오픈 이후 **보안 유출 사고 0건**을 유지하며 성공적으로 사내 배포를 수행했습니다.
- **데이터 유실 가능성 0%**: 파일 데이터를 RDBMS 테이블에 완전 통합함으로써 백업·복구 정합성 불일치로 인한 **데이터 유실 리스크를 근본적으로 차단**했습니다.
- **기술 내재화**: JPA(Java Persistence API) 프레임워크를 실무에 성공적으로 접목함으로써, 현대적인 객체-관계 매핑(ORM) 백엔드 기초 설계 역량을 단단하게 내재화했습니다.
