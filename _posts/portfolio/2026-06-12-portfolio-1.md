# DelayNoMore <span class="badge">개인 프로젝트</span>

> "계획을 고칠 수 있다는 여지"가 미루기를 만든다고 보고, 계획을 확정하는 순간 수정·삭제 권한을 박탈하는 **잠금(Immutable Lock) 모델**을 검증한 서비스입니다.
> **Spring Boot(Java 21) + React + PostgreSQL** 풀스택으로 직접 설계·구현하고, **단일 컨테이너로 배포**하며 **AI 호출 비용까지 튜닝**한 백엔드 중심 프로젝트입니다.

![DelayNoMore 핵심 지표](/assets/images/portfolio/delaynomore-metrics.svg)

---

## 한눈에 보기

- **구분**: 개인 프로젝트 (기획 · 설계 · 개발 · 배포 단독 수행)
- **백엔드**: Spring Boot 4 · Java 21 · REST `/api/v1` · SSE · PostgreSQL(Supabase)
- **인프라**: Docker 단일 컨테이너 · GitHub Actions → ghcr.io → Oracle Cloud(Pull 배포)
- **AI**: OpenRouter LLM 프록시 (키 서버 보관) · 스트리밍 · 토큰 비용 최적화
- **GitHub**: [github.com/hello-pebble/DelayNoMore_Release](https://github.com/hello-pebble/DelayNoMore_Release)

![기술 스택 레이어](/assets/images/portfolio/delaynomore-stack.svg)

---

## 콘셉트 — "계획은 신중하게, 실행은 강제로"

AI 코치가 목표·기간·가용 시간을 대화로 수집해 **하루 단위 실행 계획**을 만들고, 사용자가 확정하면 그 계획은 **완료 체크만 허용**되는 잠금 상태로 들어갑니다. 수정·삭제라는 도피로를 구조적으로 없애 미루기를 차단하는 것이 서비스의 핵심 가설입니다.

![DelayNoMore 사용자 워크 프로세스](/assets/images/portfolio/delaynomore-flow.svg)

---

## 시스템 아키텍처

프론트엔드·백엔드·AI 프록시를 **하나의 Docker 컨테이너**로 묶어 저사양 무료 VM에서도 단순하게 배포됩니다. Spring Boot가 빌드된 React 정적 파일과 `/api/v1` REST·SSE를 함께 서빙하고, OpenRouter 키는 서버에만 보관하며, 상태는 PostgreSQL(Supabase)에 영속화됩니다.

![시스템 아키텍처](/assets/images/portfolio/delaynomore-architecture.svg)
